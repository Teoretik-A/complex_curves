# Комплексные кривые

Интерактивная визуализация комплексных кривых: отображение z → w показывается в четырёхмерном пространстве (Re z, Im z, Re w, Im w) с проекциями на z-плоскость и w-плоскость. Рендеринг — WebGL 2 с автоматическим откатом на CPU.

**Живая страница:** https://teoretik-a.github.io/complex_curves/

## Возможности

- Готовые кривые: окружность, парабола, гипербола, гипербола взаимности (zw = 1), кубическая парабола, прямая, касп (w² = z³), узловой узел (w² = z²(z+1)), **эллиптическая кривая (w² = z³ − z)**, экспонента.
- Произвольные формулы: `w = f(z)` или неявные `F(z, w) = 0` (примеры: `w^2 = z^3 - z`, `z^3 + w^3 = 1`, `w = sin(z)`).
- Режимы раскраски: фаза комплексного числа, глубина, модуль, «золото».
- Режимы поворота: смешанный z/w, внутри z / внутри w, перекрёстный, экран.
- Дополнительно к плоскостям z и w — смешанная плоскость Re w × Re z (галочка).
- **Панель среза** под сценой: точка z₀ (или w₀ — переключается) ставится и двигается мышью на мини-плоскости; на поверхности подсвечиваются все точки кривой с этим фиксированным значением, координаты решений выводятся списком (клик по строке — отметить точку).
- Визуализация римановой поверхности, сетки, линий уровня, вещественных сечений.
- Выделение точек, вычисление корней уравнения F(z, w) = 0, матрица проекций.
- Масштабирование, авто-вращение, адаптивная вёрстка (мобильные устройства поддерживаются).

## Управление

- Перетаскивание мышью / касанием — поворот сцены.
- Колесо мыши / кнопки `+` `−` — масштаб, `1:1` — вернуть исходный вид.
- Клик по плоскости — выделение точки.

## Запуск локально

Достаточно открыть `index.html` в браузере с поддержкой WebGL 2, либо:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```
